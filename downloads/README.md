# Downloads

This directory contains the SavahLive Android source archive (`SavahLive-android-source.zip`). It is a source package, not an installable APK.

For the current downloadable APK entry, version, checksum, and signing-status warning, use the [root README Downloads section](../README.md#downloads) and the linked GitHub release. Verify the SHA-256 after downloading. A checksum confirms file integrity; it does not establish that an APK is signed.

SavahBot's dashboard and backend are deployed services and are not distributed from this folder.
